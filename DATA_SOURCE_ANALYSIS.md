##  How to Switch Data Sources

### Option 1: Use Real Network Capture

**Step 1**: Edit `.env` file:
```bash
MOCK_MODE=false
PCAP_FILE=
```

**Step 2**: Ensure TShark is installed:
```bash
tshark -D
```

**Step 3**: Set correct interface:
```bash
CAPTURE_INTERFACE=5  # Your Wi-Fi interface
```

**Step 4**: Restart backend:
```bash
cd backend
python main.py
```

**Result**: Frontend will show REAL packets from your network.

---

### Option 2: Use PCAP File (DNS Remote Shell Attack)

**Step 1**: Edit `.env` file:
```bash
MOCK_MODE=false
PCAP_FILE=dns-remoteshell.pcap
PCAP_LOOP=true
PCAP_SPEED=1.0
```

**Step 2**: Restart backend:
```bash
cd backend
python main.py
```

**Result**: Frontend will show packets from the PCAP file (DNS tunneling attack).

#### PCAP Replay Options

**Speed Control:**
- `PCAP_SPEED=1.0` - Realtime playback
- `PCAP_SPEED=2.0` - 2x speed
- `PCAP_SPEED=0.5` - Half speed
- `PCAP_SPEED=0` - As fast as possible

**Looping:**
- `PCAP_LOOP=true` - Replay indefinitely
- `PCAP_LOOP=false` - Play once and stop
