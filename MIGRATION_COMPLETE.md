## How to Use

### Option 1: Real Network Capture

```bash
# Terminal 1: Backend (real capture)
cd backend
python main.py

# Terminal 2: Frontend
cd frontend
npm run dev

# Browser: http://localhost:5173
# Will show REAL IPs from your network
```

### Option 2: Mock Data from Backend

```bash
# Terminal 1: Backend (mock mode)
cd backend
CAPTURE_MOCK_MODE=true python main.py
# Or edit .env: CAPTURE_MOCK_MODE=true

# Terminal 2: Frontend
cd frontend
npm run dev

# Browser: http://localhost:5173
# Will show 33 diverse mock IPs from backend
```

## Troubleshooting

### No events appearing
```bash
# Check backend is running
curl http://localhost:8000/status

# Check backend logs
# Should see "Emitting X condensed events"
```

### Only a few IPs
- Wait 30-60 seconds for diverse traffic
- Check backend mock mode is enabled
- Look for "Generating anomaly spike" in logs

### Frontend shows "Disconnected"
- Backend must be running first
- Check port 8000 is not in use
- Verify no firewall blocking
